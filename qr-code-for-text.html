QR Code for Text

A text QR code stores plain words inside the pattern. Nothing is fetched from the internet, so it works with no connection at all.

Last updated: October 2026 · Free · no account · no watermark

What it does: the code carries the text itself. Scanning it shows the words on screen — no link, no server, no loading. That makes it the most durable QR type there is.

Most QR codes are pointers. A text QR code is the content. Because the data lives inside the pattern, a text code works in a basement with no signal, on a device with no data plan, and in ten years' time when whatever website it might have pointed at is long gone.

The trade-off is capacity. Text is bulky compared with a URL, so the more you encode, the denser the pattern and the smaller it has to be printed to stay scannable. Short and specific beats long and complete.

How to create a text QR code

  1. Choose the Text type Open Make My QR Code and select Text from the type list.
  2. Type or paste your text Line breaks are preserved. Keep it as short as it can be while still being useful.
  3. Check the preview If the pattern looks very dense, your text is long. Shorten it before printing small.
  4. Download the PNG Generate at the largest size available.
  5. Scan it yourself Read the text back from your own phone to confirm nothing was truncated.

Where people use it

  • Equipment serial numbers and asset tags
  • Coupon codes and reference numbers
  • Safety and handling instructions on equipment
  • Wi-Fi alternatives where a network is unavailable
  • Offline inventory labels in warehouses and basements
  • Short notes, passwords for a guest network, or locker codes

Best practices

  • Keep text under about 300 characters for reliable scanning at small print sizes.
  • Use capital letters and digits for codes &mdash; they are less ambiguous than similar-looking lowercase characters.
  • Avoid emoji and unusual symbols if the code will be read by older scanners.
  • Print larger than you think you need. Dense text codes punish small sizes.

Frequently asked questions

How much text fits in a QR code?

Technically up to around 4,000 alphanumeric characters at the lowest error-correction level. Practically, keep it under 300 characters so the code stays easy to scan when printed small.

Does a text QR code need internet?

No. The text is stored inside the code, so it displays even with no connection.

Can I edit the text later?

No. Once the code is generated the content is fixed. Generate a new code if the text changes.

Will my text be readable after scanning?

Yes, scanners display it as plain text. Some also offer a copy button.
