What Size Should a QR Code Be in Print?

Size the code for the distance it will be scanned from, not for the space it happens to fit in.

Last updated: October 2026 · Written by the Make My QR Code team

Rule of thumb: allow 1 cm of code width for every 10 cm of scanning distance. A code read at 30 cm needs about 3 cm. One read across a room needs 20 cm or more. Never go below 2 cm — and always print a physical proof before the full run.

The sizing table

UseTypical scan distanceMinimum code width
Business card20–30 cm2 cm
Flyer or brochure30–40 cm3 cm
Table card / menu insert30–50 cm4 cm
Poster in a corridor1–2 m10–15 cm
Shop window2–3 m20–30 cm
Outdoor sign or billboard5–10 m50–100 cm

These are starting points, not laws. A code that fails at the recommended size is usually failing for another reason — contrast, print quality, or a payload that is too dense.

What changes the required size

  • Data density. A short URL creates a sparse pattern with large modules. A long URL, a full vCard or a paragraph of text creates a dense pattern with tiny modules — and small modules are what actually fail. This is the most underrated factor.
  • Error correction level. Higher correction tolerates damage but adds modules. If you need a logo overlay, you pay for it in density.
  • Print quality. Inkjet on absorbent paper bleeds. Laser on smooth stock stays crisp. Bleed closes the gaps between modules and kills scanability.
  • Contrast. Dark modules on a light background. Reversing it (light on dark) fails on many scanners.
  • Lighting and angle. A code behind glass, on a curved surface, or lit from above with a reflection is harder to read than the same size on flat matte paper.

The quiet zone

Leave a blank margin around the code of at least four modules — roughly 10% of the code width on each side. Designers crop this constantly because it looks like wasted space. Without it, scanners cannot find the code's edges and simply fail.

How to test before you print

  1. Print one copy at the final physical size, on the final paper stock.
  2. Scan it at the real distance, in the real lighting, with two different phones.
  3. Try it with the screen brightness low — that is how people actually scan.
  4. Try scanning from an angle, as someone walking past would.
  5. If any of those fail, increase the size or shorten the payload rather than hoping.

Vector is not optional for large format

A 300×300 pixel PNG stretched to 60 cm is a blurry grid with soft module edges, and scanners will struggle. For anything larger than roughly A4, use a vector format: SVG scales to any size without loss and keeps the module edges sharp. If your printer insists on PDF or EPS, they can usually convert from SVG.

Frequently asked questions

What is the minimum size for a QR code?

About 2 cm square for something read at close range, such as a business card. Below that, print quality and camera focus start to fail.

How many pixels should a QR code be for print?

At least 300 pixels for every inch of printed width. A 3 cm code (about 1.2 inches) therefore needs roughly 400 pixels minimum, and more is safer.

Do I need a quiet zone around a QR code?

Yes. Leave a blank margin of at least four modules on every side, or scanners may fail to detect the code at all.

Does a white border count as the quiet zone?

Yes, as long as it is genuinely blank and not printed with a background pattern or image.

Can a QR code be too large?

No. Larger is easier to scan. The only practical limits are design space and printing cost.
