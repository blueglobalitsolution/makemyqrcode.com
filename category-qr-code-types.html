How QR code types actually differ

Every QR code holds the same thing: a short string of data. What changes between types is the format of that string. A website code holds a URL. A Wi-Fi code holds a network name and password in a structure phones recognise. A vCard code holds contact fields. The phone reads the format and decides which app to open.

That is why choosing the right type matters more than choosing the right colour or logo. A URL code that points at a contact page is not the same experience as a vCard code that saves your details into someone's address book, even though both end up on the same website.

How to choose the right type

Work backwards from what the person should be able to do in the three seconds after they scan. If the answer is "open something", use a link type. If it is "join something", use a credential type. If it is "keep something", use a contact or calendar type.

  • They need to reach a page or file — use a website link code, even if that page is a menu, a video or a PDF.
  • They need to join your network — use a Wi-Fi code so nobody has to read a password off a card.
  • They need to save your details — use a vCard code rather than a link to your contact page.
  • They need to reach a human — a phone or email code removes the typing step entirely.
  • They need to remember a date — use an event code that adds itself to their calendar.
  • They need to find you — a location code drops a map pin at your door.
  • They need to pay — use a crypto code so the address cannot be mistyped.

Two practical cautions. First, every extra character makes the pattern denser, so prefer the leanest type that solves the problem — a URL pointing at a hosted vCard is heavier than a compact vCard code, but a full contact record with a photo can be heavier still. Second, all of these are static codes: they store their data permanently and cannot be changed after printing.

Frequently asked questions

What are the main types of QR codes?

The common types are website link (URL), plain text, email, phone call, SMS, vCard contact, Wi-Fi, location, calendar event and cryptocurrency payment. Each stores a different data format, which determines what the phone does after scanning.

Which QR code type should I use for a restaurant menu?

A website link code, pointed at a mobile-friendly menu page rather than a PDF. A PDF forces pinching and zooming on a phone. The menu is content, not a QR type, so the right code is simply a URL.

Can I change the type of a QR code after printing?

No. The data format is baked into the pattern. Changing the type, the destination or the Wi-Fi password requires generating and printing a new code.

Do all QR code types expire?

No. Every type generated by Make My QR Code is static and permanent. Codes only expire if they rely on a third-party redirect service that stops running.

Do all QR code types need internet?

The scan works offline for text and Wi-Fi codes because the data is inside the pattern. Link, location, email and calendar codes still need a connection on the phone to complete the action.
